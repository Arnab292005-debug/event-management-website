# EventSphere - Responsive Event Management Website

A modern, responsive event management platform allowing users to explore upcoming events, filter by categories, view event details, and register with client-side form validation.

## 🚀 Features

- **Hero & Featured Events**: Highlights top upcoming summits with an active countdown timer.
- **Dynamic Search & Filtering**: Instant search by keyword and category filters (Technology, Music, Business, Art).
- **Interactive Details Modal**: Pop-up window displaying event schedules, speakers, venue maps, and seat availability.
- **Registration & Validation**: Real-time JavaScript validation for name, email, and 10-digit phone number.
- **Digital Pass Generation**: Generates an interactive ticket pass upon successful registration.
- **Bonus Enhancements**:
  - Light/Dark mode switcher with persistent preference.
  - LocalStorage-based ticket management drawer to view and cancel registrations.
  - Fully responsive layout across mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3 / Tailwind CSS**: Responsive utility layout and animations
- **JavaScript (ES6+)**: DOM manipulation, validation, and LocalStorage data handling
